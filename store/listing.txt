=== SHORT DESCRIPTION (max 132 chars) ===
Save the visible part of any page as a PNG with one keyboard shortcut. No dialogs, no uploads, no data collected.

=== DETAILED DESCRIPTION ===
viewsnap saves what you see with one keystroke.

Press Ctrl+Shift+S (Cmd+Shift+S on macOS) and the visible part of the current tab is saved as a PNG in a folder inside your Downloads. There is no Save As dialog and no editor to click through.

FEATURES
• One shortcut: capture and save in a single key press
• Saved to a subfolder of Downloads (default: "Screenshots")
• Filenames you control, built from a template with placeholders:
  %host – site name (e.g. github.com)
  %title – page title
  %Y %m %d – date
  %H %M %S – time
  Default: screenshot - %host - %Y-%m-%d %H_%M_%S
• Characters that aren't allowed in filenames are removed automatically
• Works in Chrome, Vivaldi, Brave, Edge and other Chromium browsers

CHANGING THE SHORTCUT
Open chrome://extensions/shortcuts and set a new key for "Save the visible viewport as PNG". If the default shortcut is already used by your browser, your OS or another extension, set a different one there.

PRIVACY
viewsnap makes no network requests and collects no data. Screenshots go straight to your disk, and settings stay on your device. It needs only three permissions: activeTab (capture the current tab when you press the shortcut), downloads (save the file) and storage (remember your settings).

LIMITATIONS
Browsers block capture on their own internal pages (chrome://, the Web Store, and similar). viewsnap captures only the visible viewport, not the full scrolling page.

=== SINGLE PURPOSE ===
Save a screenshot of the visible area of the active tab to the user's Downloads folder when the user presses a keyboard shortcut.

=== PERMISSION JUSTIFICATIONS ===
activeTab: Needed to capture the visible area of the current tab with chrome.tabs.captureVisibleTab. Access is granted only when the user presses the extension's keyboard shortcut.
downloads: Needed to save the captured PNG to a subfolder of the user's Downloads directory without a Save As dialog.
storage: Needed to save the user's two settings (subfolder name and filename template) locally with chrome.storage.local.
